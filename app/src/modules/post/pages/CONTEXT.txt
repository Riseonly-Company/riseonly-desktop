================================================================================
modules/post/pages — screens only
================================================================================

  posts/  the feed. Three tabs over one repository — the same repository
          modules/user reads for a profile's post tabs.

ONE LIST PER TAB

  A `ListUi` carries a scroll position and gpui's `ListState` is a SumTree of
  MEASURED rows. Sharing one across tabs would either lose the position on every
  switch or keep it and scroll the new tab to a row that is not there.

SPLICE, DO NOT RESET

  A page appended while the user is reading must not move the viewport, so a
  longer feed is spliced at the end. A SHORTER one is the account-switch case and
  is the only place a reset is correct.

THE SKELETON IS ONE ANIMATION

  Five cards times seven shapes is thirty-five placeholders. gpui has no damage
  regions, so thirty-five independent sweeps would each repaint the window —
  `SkeletonUi::group` drives them all from one.
